# 阶段 1-5：执行控制验收与快速审核

日期：2026-09-05。范围：ROADMAP 阶段 1-5，依据需求 §7.5、§7.6、§10.1。

## 验证

- Debug、Release × x86、x64：Step Into 进入被调用方法、Step Out 返回调用方、Step Over 跳过调用；实际停止源码行与样例标记逐项比较。
- 验证重复 Continue、停止时 Pause、缺失/非法线程、终止后命令的明确错误。
- 执行等待超时及取消后目标暂停，仍可继续。会话状态事件序号连续。
- 启动与附加模式 Detach 后目标存活且可继续到正常退出；带有效断点 Detach 正常清理。
- 停止和运行中的启动目标均可 Terminate 并观察 ExitProcess；附加目标 Terminate 被拒绝且目标存活。
- 两种配置均通过全部 39 项单元测试和阶段 1-4 双架构断点回归。
- 复现：`eng/verify-stage1-5.ps1 -Configuration Debug` / `-Configuration Release`。

## 快速审核与必要修复

| 发现 | 决策 | 修复与证据 |
|---|---|---|
| 运行中 Terminate 返回未同步错误 | 采纳 | 先同步停止，再终止；新增真实运行中 Terminate 回归 |
| Detach 应同时释放活动 Stepper | 采纳 | 在同步停止内停用 Stepper，再清理断点及 Detach |
| 旧取消重入测试可能提前注销待验证回调 | 采纳 | 等待回调本身完成，保留有界等待；不改调度器逻辑，39 项测试通过 |
| 执行控制测试失败可能遗留自建目标 | 采纳 | 对测试创建的目标增加 finally 清理，并核实清理已遗留的测试 PID |

结论：阶段 1-5 可原位勾选，未扩大为 MCP 或第二套调试后端。
