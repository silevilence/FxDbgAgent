# 阶段 1-7 参数与局部变量验收

日期：2026-09-05。范围：ROADMAP 阶段 1-7，需求 §7.8、§10.3。

- Core 的 VariableReader 管理单次停止中的引用身份、循环检测、深度和总成员预算；Interop 仅读取原生值及元数据字段，PDB 提供活动作用域的局部变量槽名。
- 默认深度 1、成员 100、字符串 256；允许深度 0～8、成员 1～1024、字符串 1～32768。成员预算包括根节点和后代，根分页优先保留，数组按索引直接读取；十万元素数组尾页不遍历前面元素。
- Continue、退出、Detach 使原帧与变量引用失效。空值、优化掉、无法读取具有不同状态；CLR 返回 IL_VAR_NOT_AVAILABLE 才标为优化掉，其余读取错误保留 HRESULT 诊断。Release x64 的样例末参数实测可能返回 READVIRTUAL_FAILURE，不能伪装为空值或优化掉；可读空字段在全部配置中验证为 Null。
- 覆盖参数、局部变量、实例/静态字段、基础值、截断和完整字符串、循环引用、按需展开和分页、非法预算、过期引用。样例 Getter 和 ToString 带副作用计数，正常退出确认从未调用。

验证：`eng/verify-stage1-7.ps1 -Configuration Debug` 和 `Release` 均通过；单元测试 51 项通过，真实 x86/x64 变量组合通过，读取组合限制 5 秒。追加双配置双架构线程/14 层栈回归通过，构建零警告、零错误。

快速审核已修复必要阻塞：元数据枚举 S_FALSE 结束、ClrDebug 短缓冲区字符串包装边界、字符串误当对象字段枚举、完整字符串尾字符丢失，以及 PDB 作用域枚举失败时剩余 COM 引用释放。未执行用户代码，没有增加目标状态写入路径。

结论：阶段 1-7 可原位勾选。
