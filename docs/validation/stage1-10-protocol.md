# 阶段 1-10 协议与生命周期验收

日期：2026-09-05。范围：ROADMAP 1-10、需求 §5、§10.1。

实现细节见 [Engine 协议](../engine-protocol.md)。请求、响应、事件通过 Named Pipe JSON-RPC 复用；Host 保持架构路由，Engine 保持单一调度线程和同一调试实现。

验证：`eng/verify-stage1-10.ps1 -Configuration Debug` 与 `Release` 均通过，单元测试 57 项通过；双架构真实 Host/Engine 测试覆盖断点、栈、变量、模块和有序事件、协作超时保留暂停、客户端取消后的 Detach、5 次重复附加/分离后的句柄与进程清理。

崩溃注入：杀死单独 Host 辅助进程后，Engine 退出且已暂停的附加目标存活，并可重新附加。杀死 Engine 后 Host 返回明确错误、活动会话清除且能再次工作。额外观察：Engine 硬崩溃时 Desktop CLR 目标会退出，已如实记录于协议文档；该行为不能等同于 Host 断开后的安全 Detach。所有注入仅作用于本仓库测试进程。

协议单元测试覆盖多并发响应关联、取消送达远端、连接仍可复用、心跳维持空闲连接、沉默对端超时、帧上限、截断、重复 JSON 字段和非对象拒绝。快速审核补充本机/预期 Engine PID 校验，双配置 Host 启动/附加回归通过；修复关闭与请求错误竞态，限制 Core 事件历史且不复用序号。

结论：阶段 1-10 可原位勾选。Engine 硬崩溃后的目标存活不作为已实现保证；需求中的 Host 崩溃尝试安全 Detach、Engine 崩溃隔离均有真实证据。
